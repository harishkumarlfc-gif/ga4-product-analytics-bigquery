# User Analytics

## Overview

Understanding users is at the core of product analytics.

While Product Analytics focuses on what products perform well, User Analytics focuses on how users interact with the product, how they behave throughout their journey, and which users create the most business value.

This module analyzes user behavior using the Google Merchandise Store GA4 dataset.

---

## Data Source

Google Analytics 4 (GA4) Public Ecommerce Dataset

---

## Analyses Included

### 1. User Segmentation

Classify users based on purchasing behavior.

Key metrics include:

- Buyers vs Non-buyers
- Total Users
- Purchase Rate

---

### 2. Behavior Analysis

Understand how users interact with the store.

Key metrics include:

- Product Views
- Add to Cart
- Checkout
- Purchase
- Event Distribution

---

### 3. User Journey

Analyze the path users take from first interaction to purchase.

Key metrics include:

- Journey Stages
- User Progression
- Funnel Completion

---

### 4. Customer Lifetime Value (CLV)

Measure the total revenue generated by individual customers.

Key metrics include:

- Revenue per User
- Orders per User
- Average Customer Lifetime Value

---

## Business Value

These analyses help product managers answer questions such as:

- Who are our most valuable users?
- Where do users spend the most time?
- Which behaviors indicate a higher likelihood of purchase?
- Which customers generate the highest long-term value?
- How can we improve user retention and engagement?

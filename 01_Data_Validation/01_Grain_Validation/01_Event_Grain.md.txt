# Event Grain Validation

## Business Question

Does one row in the GA4 events table represent one event?

---

## Expected Result

Each row should represent a single user event.

Expected Grain:

> One Row = One Event

---

## Observation

The query returned individual GA4 events such as page_view, session_start, first_visit, view_item and purchase.

Each record corresponds to one user interaction generated at a specific timestamp.

No evidence suggests that multiple events are stored within a single row.

---

## Validation Result

✅ PASSED

---

## Business Impact

Since the raw dataset is stored at event level, event-based metrics such as:

- Event Count
- User Journey
- Funnel Analysis
- Feature Usage

can be calculated correctly.

---

## Key Learning

Understanding dataset grain is the first step before performing any aggregation or KPI calculation.
